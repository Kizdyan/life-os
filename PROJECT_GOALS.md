# Life OS / Persona — product outcomes

## Mission
Build a usable, cloud-accessible content production system for an actor and musician, from original idea through script, shoot plan, media production, quality review, publication preparation and evidence-based learning.

## Required user journeys
1. On iPhone, choose a content goal and create several distinct Reel or carousel concepts.
2. Review factual sources, creative options and independent editorial criticism; user approves the final script.
3. Produce a shoot-ready page: hook, spoken lines, shots, lighting, location, sound and edit plan.
4. Upload footage from iPhone, submit a persistent rendering job, review output and download an MP4.
5. Produce a readable carousel as exported images, not merely a draft.
6. Record real Instagram metrics and compare outcomes without inventing numbers.

## Non-negotiables
- No required personal computer for normal operation, validation or release.
- No production deployment, main branch merge, data deletion, paid infrastructure or changes to approved creative work without explicit authorization.
- Existing branches, services, projects and media are preserved.
- Source changes are not proof of working features.
- Human approval remains the final creative decision.
- Portable architecture: separate source, build, persistent storage and rendering workers.

## Evidence hierarchy
Proposed < implemented < static check < passing automated test < deployed preview < tested end-to-end on a real iPhone with real media.
Report the exact level achieved; never upgrade evidence by implication.
