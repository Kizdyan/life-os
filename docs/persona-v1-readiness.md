# Persona: карта готовности и критерии завершения V1

> Срез на 2026-11-02. Это карта **доказательств**, а не оценка готовности в процентах. Для нового SHA результаты CI необходимо проверять заново.

## Что является продуктом

**Первая полезная версия (V1):** пользователь создаёт сценарий и Production Brief, проверяет реальный MP4, получает три локальных цветовых варианта, видит исходник и обработку, выбирает вариант с комментарием и после перезагрузки видит сохранённое решение. Авторское решение не разрешает публикацию.

**Долгосрочная Persona:** автоматизированное производство Reels от идеи до монтажа и финальной художественной проверки. Она **не** равна Comparison Studio; готовность всех её подсистем пока не доказана.

## Definition of Done: Comparison Studio V1

V1 можно **закрыть**, только если выполнены все условия:

- [ ] GitHub Actions для одного и того же финального SHA PR #138: обязательные `core`, `Media Brain CI` и `deploy-readiness` — SUCCESS.
- [ ] Реальный синтетический FFmpeg MP4 → CLI → папка из **ровно пяти** файлов: копия исходника, три обработанных MP4 и `COMPARISON.json`; оригинальный MP4 побайтово неизменён.
- [ ] Проверка SHA каждого файла, отсутствие переноса выбора на другой SHA, отсутствие разрешения публикации.
- [ ] Chrome E2E в интерфейсе Persona: импорт пяти файлов, переключение вариантов, сравнение, сохранение выбора B с комментарием, reload, восстановление решения и повторный импорт для нового просмотра.
- [ ] В Chrome проверена ширина 390 px и отсутствие ошибок страницы.
- [ ] На **одном явно предоставленном автором реальном MP4** создано три обработки и выполнен авторский просмотр. Зафиксированы конкретные замечания о цвете кожи, очках, свете, детализации и звуке.
- [ ] Подтверждённые критические дефекты исправлены, известные ограничения задокументированы.
- [ ] Подготовлена короткая инструкция для Windows; PR остаются Draft до отдельного решения о ревью и интеграции.

### Что НЕ блокирует V1

- Рендер из кнопки интерфейса вместо локальной команды — следующий UX-этап, **не** условие первого полезного испытания.
- AI-анализ актёрской игры, подбор музыки, персональная модель стиля и публикация — отдельные задачи.
- Более сложная цветокоррекция — только после первого просмотра **реального** авторского материала.

## Ближайшее действие

4. Исправить только дефекты, обнаруженные во время этих двух испытаний, и закрыть V1 по чек-листу.

## Границы безопасности и честности

- Нет автоматической публикации и автоматического художественного одобрения.
- SHA-256 подтверждает идентичность файлов, **не** кинематографичность результата.
- Исходный MP4 не перезаписывается. Цветовые пресеты не изменяют геометрию и не выполняют генеративную ретушь.
- Подтверждённые данные, авторские оценки и гипотезы о стиле хранятся и описываются раздельно.
- Stacked PR #138 основан на PR #137; оба Draft. Зелёный CI **не означает**, что изменения уже внедрены в `main`.
