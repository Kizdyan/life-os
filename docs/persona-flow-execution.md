# Persona: рабочий маршрут от идеи до MP4

Никаких шаблонных обещаний: модель реально генерирует идеи и сцену, существующие Whisper/Ollama/FFmpeg действительно собирают видео, а упаковщик проверяет готовый файл.

## Шаг 1. Реальная нейросеть создаёт 3 идеи и съёмочный сценарий

Из корня Life OS в PowerShell:

    npm run persona:flow -- prepare "Актёр спорит с композитором: музыка меняет жанр сцены" "C:\Users\Kostya\Documents\LifeOS\Persona\private-media\idea-run-new" "docs/persona-model-servers.example.json" humor

Создаётся новая папка. В ней: IDEAS.json с 3 предложениями, PRODUCTION-BRIEF.json с 4–8 кадрами, SHOOT.md с репликами/светом/ракурсами, FLOW.json со статусом WAITING_FOR_FOOTAGE. Сценарий является неутверждённым творческим черновиком. Отсутствующая модель даёт реальную ошибку, а не шаблон.

Файл конфигурации поддерживает до восьми явно разрешённых Ollama-совместимых серверов, с проверяемым failover. Для внешних серверов разрешён только HTTPS, для локальных HTTP loopback. Не помещайте секреты прямо в JSON: поле tokenEnv задаёт имя переменной окружения.

## Шаг 2. Человек снимает реальные дубли

Снимите кадры по SHOOT.md: S01_take01.mp4, S02_take01.mp4 и т. д. Несколько дублей одной сцены допустимы. Реконструкция реального лица из нейросети не используется.

## Шаг 3. Whisper + Ollama + FFmpeg создают настоящий MP4

    npm run persona:flow -- render "C:\...\idea-run-new" "C:\...\TAKES" "C:\...\NEW-RENDER" "C:\...\whisper-cli.exe" "C:\...\ggml-multilingual.bin" "qwen3:4b-instruct" humor

При успехе: ai-edited-reel.mp4, draft-reel.mp4, decisions.ai.json, ai-edited-qa.json, RESULT.json, пакет трёх вариантов цветокоррекции. Если речь не распознана, генерируется Recovery или точная ошибка. Никаких придуманных дублей и таймкодов. Исходники не изменяются.

## Шаг 4. Создать проверенный файл для выгрузки

    npm run persona:flow -- package "C:\...\NEW-RENDER\RESULT.json" "C:\...\NEW-DELIVERY" "Текст публикации"

В новой папке: persona-reel.mp4, caption.txt, DELIVERY.json. Файл действительно копируется, SHA-256 проверяется по реальному QA; при несовпадении экспорт завершается ошибкой. Состояние AWAITING_AUTHOR_REVIEW — техническая подготовка не равна авторскому разрешению.

## Ограничение внешней публикации

В Metricool на момент проверки не подключена ни одна соцсеть. Поэтому отправка в Instagram сейчас заблокирована внешней настройкой аккаунта. После подключения нужна разрешённая площадкой загрузка видео и реальная операция планирования/публикации; копирование MP4 не выдаётся за опубликованный Reels.

Веб-интерфейс Persona пока не умеет самостоятельно запускать установленные на Windows FFmpeg/Whisper/Ollama. Команды выше — настоящий локальный путь, но ещё не единая кнопка в браузере.

## Тестирование

В CI проверяются формат и происхождение реальных модельных ответов (тестовый mock только в тестах), отказы и несколько серверов, а также реальный синтетический MP4 с независимой ffprobe/FFmpeg-проверкой. Это техническая проверка кода, а не утверждение результата на личном видео.
