# Life OS iPhone — приёмка крупного этапа «Надёжный ежедневник»

Дата подготовки: 27 октября 2026. Ветка: `experiment/persona-lifeos-try-now-20261026`, PR #107.

## Пользовательский результат

Одна тестовая версия Life OS для iPhone, в которой можно:
- выбрать сегодня, завтра или произвольную дату и просмотреть её задачи;
- создать задачу с точными часами через Эрику и сразу перейти к нужному дню;
- изменить название, дату и диапазон времени;
- получить явное сообщение о пересечении с другой запланированной задачей;
- отметить выполнение, невыполнение, исправить ошибочную отметку через «Изменить → Вернуть задачу в запланированные»;
- удалить ошибочную локальную задачу только после подтверждения;
- выгрузить и импортировать JSON-архив локальных задач и решений Persona.

Всё перечисленное относится **только к локальному режиму** `?local=1`, за исключением уже существующих команд Эрики и отметок Supabase. Никакой новой облачной синхронизации эта работа не добавляет.

## Критичные дефекты, ради которых начат этап

1. Ранее повреждённый JSON `life-os:local-runtime:v1` мог трактоваться как пустое состояние, после чего новая задача перезаписывала прежние данные. Теперь чтение и запись должны останавливаться с явной ошибкой, сохраняя оригинальное значение.
2. Повторное нажатие «не выполнено» на задаче с `carry_forward` могло повторно создавать задачу на следующий день. Новый обработчик повторного действия идемпотентен.
3. Старый интерфейс не позволял исправить дату/время созданной задачи; также отсутствовал просмотр произвольного дня.
4. Ошибочная попытка создать задачу с пересечением по времени должна останавливаться **до записи**, с названием конфликтующей задачи.
5. Неизвестный task ID теперь должен завершаться ошибкой, а не создавать «призрачную» запись.
6. Ошибка ID-генератора или опасный idempotency key не должна изменять сохранённый план.

## Автоматизированные проверки, включённые в код

`apps/web/src/localRuntime.test.ts`: создание и повторный запуск плана, завершение, перенос, повторный перенос, изменение даты/названия, запрет некорректных дат, конфликтов, работа с несуществующей задачей, сохранение повреждённых данных, корректное удаление и предотвращение дубликатов ID.

`apps/web/src/react-mount-smoke.test.ts`: отрисовка Today, Persona, Erika, выбора даты и формы редактора с точными значениями времени.

Существующие `apps/web/src/data-portability.test.ts`: экспорт, объединение, повторный импорт, некорректные архивы, отсутствие посторонних токенов в выгрузке.

## Ручная проверка iPhone — ОБЯЗАТЕЛЬНА перед завершением этапа

- [ ] Открыть стабильный Preview, создать через Эрику задачу «Сегодня с 11:00 до 11:30 ...».
- [ ] Повторить ту же команду; удостовериться в отсутствии дубля.
- [ ] Создать задачу на завтра и проверить, что открылась нужная дата.
- [ ] Изменить задачу на третью дату с новым названием и временем; перезагрузить страницу — результат сохранён.
- [ ] Попробовать пересечь время с существующей задачей; увидеть ошибку и неизменённое расписание.
- [ ] Отметить задачу выполненной, затем в редакторе вернуть её в план.
- [ ] Удалить одну из двух задач; убедиться, что другая осталась после обновления страницы.
- [ ] Сохранить резервный архив и импортировать его в чистое хранилище другого адреса, убедиться в сохранении статусов.
- [ ] Проверить читабельность мобильного интерфейса, включая клавиатуру даты/времени.
- [ ] Проверить, что повреждение хранилища показывается как ошибка и не приводит к автоматической перезаписи.
- [ ] Оценить реальную работу Safari и установленного PWA отдельно: сохранение локальных данных на другом origin **не гарантируется**.

## Честный статус и ограничения

- Последний независимо подтверждённый Vercel Preview до текущих исправлений: `daec37f8`, READY, 230/230 тестов.
- **Новые изменения этой серии ещё не получили успешной сборки**: Vercel для новых коммитов сообщает `Deployment rate limited — retry in 24 hours`. GitHub Actions также были ограничены на стороне аккаунта. Поэтому автоматические проверки нового кода пока считаются **не выполненными**, а не PASS.
- Настоящий ИИ Persona остаётся заблокирован Vercel AI Gateway `403`; этот этап не подменяет его шаблоном и не включает платный API.
- Облачная синхронизация, offline PWA с service worker, расширенные статусы/аналитика, связь с Qwen и перенос данных со старых Vercel-origin по-прежнему не приняты.
- Никаких изменений `main`, production, почты или платных сервисов.

**Этап может быть закрыт только после зелёных автоматических проверок текущего коммита и ручного iPhone smoke test.** До этого статус: код подготовлен, приёмка не завершена.
