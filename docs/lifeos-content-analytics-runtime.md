# Life OS content management and publication observations

Life OS dashboard → Контент-контур now exposes the existing weekly calendar and Stories, existing 90-day projection, and Metricool observation history. Persona remains the production workspace. Calendar actions open exact material IDs through explicit navigation routes. The legacy Persona calendar views remain available for compatibility; this is not yet a unified server-side calendar, and the weekly and rolling projections still have separate planning semantics. No saved date was moved.

Analytics imports bounded JSON arrays of version 1 MetricSnapshot records. Provider is metricool, platform instagram; URL is the publication identity; contentId is null until an explicit binding to an existing project. publishedAt is null if the source timezone is unverified. observedAt means query time, not provider refresh time. Missing metrics are null, not zero. Multiple observation times are retained, exact repeats are idempotent, conflicting same-time records or content bindings are refused. Full backup v2 contains the optional analytics history and preserves conflicts. No actual account IDs, private analytics, access tokens or publication media are committed here.
