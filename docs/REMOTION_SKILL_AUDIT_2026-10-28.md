## Новая воспроизводимая команда

Для *заранее полученного доверенным способом* локального Git checkout с HEAD ровно `30d4553ecd46fbc5212fd0ff006ae43af522158b`:

```bash
npm run skills:review-remotion -- /absolute/path/to/remotion-dev-skills /tmp/remotion-review.json
node --test scripts/remotion-skill-review.test.mjs
```

`scripts/remotion-skill-review.mjs` вызывает `verifySkillCheckout()` и проверяет:
- точный Git revision и SHA файлов по `git ls-tree`;
- размер, количество и типы файлов;
- оба SHA-256, полученные при чтении локального каталога;
- отсутствующие ссылки, опасные конструкции и явные операции с сетью/секретами/файлами;
- отдельный список `review` и `block` для проверяющего.

Отчёт `manual_review_required` **не является** разрешением на установку; `blocked` означает, что существует непройденная техническая проверка. Поля `reviewerApproved`, `mayInstallAutomatically`, `mayExecuteAutomatically`, `mayPublishAutomatically` всегда `false`. Пользовательские материалы, токены, production базы и соцсети не затрагиваются. Запись JSON производится только при переданном пути и с `wx` (не перезаписывать существующий файл).

**Контроль лицензии:** условия библиотеки Remotion зависят от типа юридического лица и использования. Лицензия конкретного `remotion-dev/skills` и право переиспользования навыков в коммерческой системе должны быть независимо подтверждены до установки/встраивания. Статус `licenseAccepted` не присваивался.

## Статус проверки
- GitHub API подтвердил факты по указанному публичному upstream Git tree и отдельно просмотренным файлам.
- Реального скачанного полного пакета Remotion в локальной среде не было; настоящий полный проход `skills:review-remotion` для 144 файлов **ещё не выполнялся**.
- Изолированные локальные Node-тесты инструментария — **20/20 PASS** на локальной копии тестируемых функций (7 Remotion review packet, 8 Git provenance, 5 вспомогательных source format/scale). Не эквивалентно полному `npm test` / `npm run typecheck` / `npm run web:build` точного GitHub SHA.
- GitHub Actions и Vercel не дают подтверждённого зелёного CI; работа ведётся в Draft PR #121.
- Следующий практический шаг: предоставленный доверенный checkout → полный read-only audit → ручная оценка findings и лицензии → изолированные Remotion/FFmpeg A/B с *тестовыми*, а не приватными файлами → только затем допуск.

## Закрыта инвентаризация статических ресурсов на pinned commit

Дополнительное чтение содержимого файлов через GitHub Blob API (не установка и не локальное исполнение):
- **88/88 Markdown-файлов** просмотрены на разрешение Markdown-ссылок относительно полного Git tree: **139 внутренних ссылок разрешаются**, отсутствующих и выходящих за пределы каталога не обнаружено. Найдены также **24 внешние ссылки**; их доступность/безопасность **не проверялась**. Анализ по Markdown-конструкции `[text](target)`, не утверждает полноту аудита всех форматов ссылок или инструкций.
- **13/13 YAML-файлов** (конфигурация агентов) прочитаны: ссылки на маленькую и большую SVG-иконку относятся к существующим файлам; явных строк с `process.env`, `secret`, `token`, `password`, `api_key` в YAML не найдено по выбранному текстовому фильтру.
- **13/13 SVG-файлов** имеют один и тот же Git blob SHA; уникальное содержимое проверено на `<script>`, inline event handlers, `javascript:` и `<foreignObject>`: совпадений по применённым правилам нет. Это не заменяет полный SVG security review.
- **10/10 JSON/GeoJSON-файлов** корректно декодируются как JSON (включая самый крупный файл размером 333 134 байта). Проверка top-level имён не выявила признаков секретов; не исключает другие риски данных.
- **20/20 TS/TSX/MJS файлов** представлены десятью парами одинаковых Git blob SHA. Уникальные десять прочитаны и проверены по базовым признакам: обнаружены локальные записи подготовительных скриптов, работа с ключами MapTiler/Google Tiles в примерах. Потребуются ручные решения по этим операциям.

Итого все 144 файла охвачены либо чтением через GitHub Blob API, либо проверкой идентичности Git SHA дубликата, **но это структурный и эвристический аудит, не подтверждение безопасности исполнения**. Фактические SHA-256 локального полного пакета, проверка checkout и полные sandbox-бенчмарки ещё не получены.

Статический сканер в PR дополнен `external_network_dependency` для JS/TS/TSX файлов с `fetch`, `@maptiler/sdk` или явным URL MapTiler/Google Tiles. Файл Markdown, содержащий URL как обычную документацию, не должен получать этот флаг. После изменений в локальной тестовой копии кода и фикстур пройдено **27/27** targeted Node-тестов (включая 7 review packet, 8 Git provenance, вспомогательные source tests и 5 видео/QA). Это по-прежнему **не подтверждение прохождения полного GitHub CI**.
