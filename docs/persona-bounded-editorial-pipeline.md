# Bounded editorial pipeline — AUD-03

Worker /carousel-editorial-pipeline uses existing token/auth, shared 5-external-calls/hour rate limit, explicit consent, maxCalls 2 or 4. Research -> independent reviewer -> at most one web-grounded revision -> reviewer. Provider-confirmed creator identity and distinct non-OpenAI critic are required. Missing provider/consent fails before calls; negative, stale, unchanged or unavailable review cannot produce an approved publication. Completed result (including prior attempt, report and last draft) is written to a unique local Worker output directory. UI imports final draft and exact verified text report without granting author approvals. Source review remains a separate human gate. Existing one-call paths unchanged.

Limits: this is one user-initiated editorial cycle, not a durable seven-item queue, scheduler or unattended background service. A crash before final result persistence can lose intermediate work; a paid request may already have occurred, so do not blindly repeat. Source-grounded revision prompt does not prove topic identity. No live model request made for development; tests inject fixtures, not real research. No new image generation, music catalog or platform sending. Actual provider identities, cost, model capabilities, full two-material production and local runtime require live acceptance. Main and external schedule untouched.
