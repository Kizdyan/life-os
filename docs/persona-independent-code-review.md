# Persona — независимая проверка изменений кода (локально)

**Статус:** экспериментальный review gate. Не является готовой Persona, сертификацией безопасности, автоматическим исправлением или художественной приёмкой ролика.

## Для чего

Codex готовит изменения в отдельной ветке. На Windows локальная Qwen через Ollama **независимо** проверяет реальный `git diff`, не получая положительный отчёт Codex. Существующий Observer отдельно запускает инструментальные тесты. Только после их сопоставления можно решать, передавать ли результат владельцу на проверку.

Жюри PR #144 оценивает творческие идеи. Этот инструмент оценивает **код**; он не заменяет и не переносит творческое жюри.

## Минимальный запуск на Windows из корня репозитория

1. Установить/запустить Ollama и убедиться, что `ollama list` показывает нужную установленную модель. Если Qwen ещё нет, сначала проверить доступное железо и согласовать загрузку.
2. В рабочей feature-ветке после коммита выполнить:

```powershell
node tools/persona-code-review-gate.mjs --base main --model qwen3:4b-instruct --out artifacts/persona-review/first-run
```

Не устанавливай модель ради теста автоматически. Для **двух слепых заключений** от разных установленных моделей добавь `--second-model <ID_ВТОРОЙ_МОДЕЛИ>`.

3. Для отдельной инструментальной проверки использовать существующий `node scripts/persona-verify-independent.mjs` на чистом коммите. Если он создал настоящий успешный отчёт, повторить проверку кода с `--observer-report artifacts/persona-verification/latest.json`, указав **новую** директорию `--out`.

Результат: `<OUT_DIR>/code-review.json` с точным SHA коммита, SHA diff, именами реально вызванных моделей и замечаниями.

## Честные статусы

- `UNVERIFIED` — Qwen ответила, но Observer не предоставил отчёт, или часть независимых проверок отсутствует.
- `NEEDS_FIX` — Qwen указала существенные **ещё не воспроизведённые** проблемы. Codex должен проверить каждую и исправить только подтверждённые.
- `BLOCKED` — имеющийся отчёт Observer не прошёл обязательные инструментальные проверки.
- `PASS` — независимая модель не сообщила существенных проблем и Observer принял отчёт **этого же SHA**. Это не разрешение на merge, deploy, публикацию или утверждение художественного качества.

Скрипт работает только с явными кодовыми путями репозитория, отказывается от подозрительных секретов и больших diff, обращается только к `127.0.0.1:11434`; исходные видео и персональные данные не загружаются.

**Облачный Codex не получает доступ к Windows localhost автоматически.** Если у агента нет Ollama, статус остаётся UNVERIFIED. Не открывать Ollama в публичную сеть.

Тест контрактов без запуска модели: `node --test tools/persona-code-review-gate.test.mjs`. Эти mock-free unit-тесты проверяют правила, **но не доказывают**, что Qwen реально запущена.
