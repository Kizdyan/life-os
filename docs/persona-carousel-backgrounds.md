# Cinematic carousel preview

In Persona → Editorial Desk, open «Почему самая страшная сцена часто тише всех». New drafts use eight different locally bundled cinematic backgrounds: stage, door handle, auditorium, spotlight, curtain, piano, black contour and final light. Six were newly generated for the v4 art revision; stage and curtain are retained. Older library files remain intact. «Кинофоны из библиотеки · все слайды» opts an existing draft into the new image sequence and resets design approval.

«Сгенерировать фон слайда · OpenAI» requests one text-free background through the authenticated local Media Worker. The worker reads `OPENAI_API_KEY` from its server environment (the existing launcher loads `.env.local`). The key never enters the browser bundle. This explicit action can incur provider charges. Missing credentials, unavailable Worker, timeout or provider failure uses the deterministic local library and displays a warning. No external API request is made on opening a draft or exporting it.

Provider configuration and automatic theme prompt: `config/carousel-backgrounds.json`. Bundled images and their provenance/fingerprints: `apps/web/public/carousel-backgrounds/v1/`. Generated images get a new immutable IndexedDB key and SHA-256; render verifies those bytes. Background references participate in the existing approval fingerprint. Old slides without background metadata retain their original hash and renderer.

Quiet Horror keeps the existing structured text model, now using only `headline` and `body` in its authored v4 composition. Cormorant Garamond 600/700 headlines and Inter 300 body text (44–48px / 1.6, opacity 0.9) load through `document.fonts.load`. Eight compositions use 100px margins, body columns up to 70% and Russian preposition-aware wrapping. No slide numbers, kickers, highlights or decorative lines appear inside the new PNGs. The slide-6 personal statement is included in both caption variants. «Применить тексты и фоны v4» updates an older saved draft and its standard caption variant, preserving custom captions; author approval remains required.

The bundled faces use renderer-only family aliases in `persona-editorial-fonts.css`. This prevents the existing app-wide Google Fonts import from replacing a face between the first render and export. Acceptance explicitly installs a competing global Cormorant face and verifies identical PNG hashes.

Canvas draws the photograph, a black-to-transparent gradient with maximum opacity 0.6, then the text. Preview and export use the same PNG. Images contain no generated lettering. `contact-sheet-quiet-horror-v4.png` replaces the v3 sheet in the explicitly mutable v4 preview release. Numbers 01–08 appear only below contact-sheet thumbnails; v1–v3 historical releases remain intact.

The workflow `persona-quiet-horror-review.yml` with `cinematic=true` exports the review-only prerelease `carousels-v4-cinematic-preview` from the selected branch, without requiring a merge. Existing tags/assets are never overwritten. `textApproved=false` and `designApproved=false` remain in the review ZIP. Provider success is covered with an injected test response; local library generation and browser export are real. A paid API generation was not run for acceptance.
