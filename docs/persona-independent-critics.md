# Independent internal critique / AI Capacity routing

## Non-negotiable requirement
Creator and independent acceptance critic must not be the same underlying model family. A different prompt, session, OpenAI version or gateway is not independence. An OpenAI model must never be the sole independent critic of Persona content. Family claims are inferred conservatively from explicit developer/model IDs and must be checked against actual provider metadata; aliases/auto-routing abstain. No paid call without consent. The author retains final publication authority.

## Implemented now
- Existing Perplexity agent factcheck endpoint requires a configured non-OpenAI critic from a different known family than the research model, checks returned model ID, and retains fetched-source evidence. A substantial editorial defect is a REVISE verdict even if all facts pass.
- Existing machine-researched (Perplexity) publication export checks current cross-family PASS on exact public copy and sources in addition to existing source/author gates. Legacy reports remain readable, but old reports without a verdict, missing reports, negative reports and stale reports do not satisfy this gate. Manual/non-researched exports retain legacy semantics; review-only exports remain available.
- Shared capability-selection helper accepts only configured candidates with verified availability and source-fetch capability; it does not itself discover providers or make calls. Current Worker still uses explicit PERSONA_CAROUSEL_REVIEW_MODEL. No automated paid fallback or live Claude/Gemini/DeepSeek access claimed.
- Unit regressions for same-family models, unknown alias, missing/stale/negative review, editorial veto and capability candidate selection.
