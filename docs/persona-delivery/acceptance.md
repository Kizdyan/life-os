### Ограничение, которое остаётся открытым

Проверка ожидаемого снимка в `localStorage` защищает от последовательного устаревшего сохранения и удаления. Но пара `getItem → setItem/removeItem` не является атомарной транзакцией между одновременно работающими вкладками. Для строгой межвкладочной сериализации нужен переход хранилища проектов/черновиков на IndexedDB transactions либо асинхронный Web Locks API с соответствующим рефакторингом UI. Не заявлять database-grade locking.
