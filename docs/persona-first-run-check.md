# Persona — проверка перед первым Reels

Запускается **локально на Windows** из каталога репозитория Life OS. Адрес 127.0.0.1 в Safari на iPhone указывает на сам телефон, а не на Windows-компьютер.

## Диагностика без видеоматериалов

В PowerShell из каталога проекта выполните:

    npm run persona:preflight

Команда не запускает Media Worker, не открывает файлы .env.local, не копирует и не удаляет медиа, не отправляет исходники и не выводит токен Worker. Для интеграций можно получить JSON без секретов:

    node tools/persona-preflight.mjs --json

- READY_TO_START — обязательные компоненты обнаружены, целевые порты свободны.
- ALREADY_RUNNING — локальная Persona уже найдена; открывайте адрес, показанный в отчёте.
- NEEDS_SETUP — требуется исправить отсутствующие компоненты, указанные в FAIL.
- BLOCKED — порт занят чужим или неполным сервисом: не завершайте процессы вслепую.

WARN vite: не найден установленный Vite, стартёр START_AUTO_RENDER.bat может выполнить npm ci при наличии доступа к сети. Зелёная проверка запуска **не гарантирует** ни работоспособности платных ИИ-провайдеров, ни художественного качества.

## Первый реальный ролик

1. Запустите START_AUTO_RENDER.bat. Обычно Persona откроется по адресу http://127.0.0.1:5173/#persona. Альтернативный START_PERSONA.bat поднимает объединённый локальный сервис на http://127.0.0.1:3000/#persona.
2. В «Быстром автомонтаже» выберите «Видео» и загрузите 1–4 **собственных** SDR-видео общим размером до 500 МиБ. Для короткого теста удобно 2–3 фрагмента не короче 8 секунд каждый.
3. Включите «Быстрый черновик», проверьте режим Vision. При активном OpenRouter отдельные JPEG-кадры могут передаваться провайдеру с платной тарификацией. Без ключа используется локальный офлайн-план.
4. Нажмите «Сделать всё», затем скачайте и лично просмотрите 720p-черновик: монтаж, речь, звук, кадрирование, естественность кожи и титры.
5. Только после этого запустите «1080p + пакет для соцсетей», скачайте готовый MP4 и доступные QC-артефакты. Автоматической публикации нет.

Не удаляйте исходники после технического PASS. Браузерный ZIP не содержит локальный Worker-видеоархив. Резервирование отдельного задания разработано в PR #199; до его интеграции и фактического создания копии на другом диске считать архив защищённым нельзя.

Испытание на **авторском** исходном материале ещё обязательно для реальной приёмки Persona.
