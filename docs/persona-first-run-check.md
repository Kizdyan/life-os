# Persona — проверка перед первым Reels

Выполняется на компьютере Windows с репозиторием `life-os`. Адрес `127.0.0.1` на iPhone указывает на сам iPhone, а не на Windows.

## Перед запуском

В PowerShell из каталога `life-os`:

```powershell
npm run persona:preflight
```

Диагностика только читает состояние локальных сервисов, Node.js/npm, FFmpeg/FFprobe и файлов приложения. Она не запускает Worker, не меняет настройки, не читает `.env.local`, не выводит токен и не обрабатывает личные видео. Для структурированного отчёта: `node tools/persona-preflight.mjs --json`.

- `READY_TO_START`: обязательные компоненты найдены, локальные порты свободны. Запусти `START_AUTO_RENDER.bat`.
- `ALREADY_RUNNING`: Persona уже работает; открой локальный адрес из диагностики.
- `NEEDS_SETUP`: проверь отмеченные FAIL компоненты перед монтажом.
- `BLOCKED`: один из портов занят чужим или неполным сервисом. Не отключай процессы автоматически.

Если `vite` имеет WARN, но нет других ошибок, `START_AUTO_RENDER.bat` сможет установить npm-зависимости при наличии сети. PASS означает только локальную техническую готовность, а не художественное качество, наличие Vision или доступность платных провайдеров.

## Первый пробный Reels

1. Открой Persona (обычно `http://127.0.0.1:5173/#persona`; для объединённого запуска `http://127.0.0.1:3000/#persona`).
2. В «Быстром автомонтаже» загрузи 1–4 настоящих SDR-видео не более 500 МБ суммарно. Для проверки удобны 2–3 клипа длительностью от 8 секунд каждый.
3. Включи «Быстрый черновик» и проверь Vision: при подключённом OpenRouter возможны платные обращения с отправкой отдельных кадров; без него работает офлайн-монтаж.
4. Нажми «Сделать всё», скачай черновик 720p и посмотри монтаж, речь, звук, цвет кожи и титры. Только после авторского просмотра запусти 1080p + пакет.
5. Сохрани отдельно исходники, финальный MP4, QC JSON и контактный лист (если доступны). Браузерный ZIP не включает локальный архив Media Worker; отдельное проверяемое резервирование пока в PR #199.

**Ограничение:** до испытания настоящих исходников невозможно подтвердить художественное качество результата; технический CI PASS не заменяет личный просмотр.
