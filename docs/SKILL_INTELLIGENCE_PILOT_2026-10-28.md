## Что изменено в коде
- `skill-intelligence.ts`: проверка Markdown-зависимостей, отсутствующих файлов, выхода за пределы пакета и совпадения лицензии из каталога с записью аудита; опасные команды глобальной установки отправляются на review.
- `skill-intelligence.test.ts`: регрессионные сценарии для missing links, traversal, mismatch license, install instructions.
- `skill-discovery-seeds.ts`: pinned upstream commit refs, но не `approved`. Digest и безопасность всего пакета остаются неподтверждёнными.
- `scripts/persona-synthetic-video-pilot.mjs`: офлайн генератор двухчастного тестового 9:16 MP4 с синтетическими рисунком и звуком, `ffprobe`, замером громкости, SHA-256 и JSON evidence. Существующие выходные файлы не перезаписываются.
- `scripts/persona-synthetic-video-pilot.test.mjs`: реальный проход через `assessPersonaReelExport` с проверкой отказа от автоматического полного допуска.

| Поле | Результат |

| True peak | −8.59 dBTP |
| SHA-256 | `1c75c828c191588ebaeeee6e5b26e6c8320833706a3165fa94c178e8074e5c06` |
| Локальный узкий интеграционный тест | **PASS: 1/1** с Node 22.16.0 и FFmpeg 7.1.5 |
| Итоговый QA | **review_required** (не full PASS) |

Эта локальная проверка не считается полноценным CI. Чёрные/замороженные кадры дополнительно осматривались через FFmpeg `blackdetect` и `freezedetect` с порогами, но надёжная автоматическая метрика в `evidence` пока не зафиксирована; поля оставлены `null`. То же касается артефактов, сохранения личности и утверждения палитры. Синтетический аудиотон не требует сторонних лицензий. Нет речи, поэтому `captionsRequired=false`, и эта проверка **не доказывает** синхронизацию титров.

## Воспроизведение
```bash
node scripts/persona-synthetic-video-pilot.mjs /tmp/persona-synthetic.mp4
node --experimental-strip-types --test scripts/persona-synthetic-video-pilot.test.mjs
```
Требуются `ffmpeg`, `ffprobe`, Node.js 22.16+; второй тест создаёт и удаляет только свои временные файлы. Перед запуском убедиться, что `/tmp/persona-synthetic.mp4` и `/tmp/persona-synthetic.mp4.qa.json` отсутствуют. Никакие чужие пользовательские медиа, соцсети, Supabase, Vercel или платные API не задействованы.
