## Дополнение: реальное MP4 evidence → Persona QA (28.10, следующий проход)

Добавлены:
- `scripts/persona-video-measure.mjs`: read-only анализ произвольного локального MP4 через фактическое декодирование FFmpeg и `ffprobe`: SHA-256, разрешение, FPS, длительность, наличие звука, интегральная громкость, true peak, оценочное количество чёрных/замороженных кадров. Используется фиксированный набор аргументов к FFmpeg; без сети, записи в исходник и вызова ИИ.
- `scripts/persona-video-qa.mjs`: соединяет измерения с **существующим** `assessPersonaReelExport()`. Возвращает `qa.status`, `blockers` и `pending`; `publishAllowed=false` во всех случаях. По умолчанию требуется верификация синхронизации титров. Проверки лица, палитры, артефактов, лицензий намеренно `null`.
- Два тестовых набора, `scripts/persona-video-measure.test.mjs` (3 кейса) и `scripts/persona-video-qa.test.mjs` (2 кейса).
- Команды в корневом `package.json`: `npm run persona:qa -- input.mp4 [report.json]`, `npm run skills:inspect -- directory`, `npm run qa:local`.

**Фактически проверено на локальных временных синтетических видео:** 3/3 measurement tests, 2/2 интеграционных tests — суммарно **5/5 PASS**, Node 22.16.0, системный FFmpeg/ffprobe. `qa=review_required` для вертикального ролика с корректными базовыми показателями (нет утверждения о личности, титрах или правах). `qa=fail` при заниженном разрешении и отсутствующем звуке.

Автоматическое распознавание статичных кадров использует эвристики `blackdetect` (0.1 c) и `freezedetect` (0.5 c) и **не является** доказательством брака при намеренно статичном изображении, например при записи экрана. Статус `fail` от применённой политики порогов для такого контента должен интерпретироваться только в контексте конкретного типа ролика. Инструмент по умолчанию не устанавливает, что субтитры вообще есть, и не определяет права на пользовательские ассеты.

**Ограничение:** тесты были выполнены локально с эквивалентной копией имеющейся функции QA; полный GitHub CI точного head пока не зелёный. Код пока не подключён к UI и не связан с кнопкой публикации. Никакие приватные исходники и данные об их контрольных суммах не коммитились.
