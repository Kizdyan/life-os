# Persona · проверка B04 по реальному аудио (Windows)

Эта функция появляется в отдельной ветке `feat/persona-asr-timecode-replay-20261104` поверх PR #145. Она **не заменяет** реальную запись, не подтверждает речь голосовой моделью и не публикует видео.

## Локальная проверка без изменения папки Codex

Используй отдельный Git worktree или копию проекта. Не переключай текущий рабочий каталог Codex, если в нём есть незакоммиченные изменения. Никогда не переименовывай и не перемещай исходные MOV/MP4.

1. На Windows убедись, что установлены Node.js 22+, FFmpeg/FFprobe, native `whisper-cli.exe` и локальная **multilingual** ggml-модель (не английская версия). Из корня отдельного worktree запусти `npm ci` и `npm run persona:preflight`.
2. Возьми **существующий утверждённый для съёмки** `PRODUCTION-BRIEF.json` и **реальную папку исходных дублей**, явно выбранную автором. Для первого теста допускается один исходный MOV, но это не доказывает наличие всех семи реплик.
3. Создай НОВУЮ директорию результата (она ещё не должна существовать). Пример PowerShell (подставь свои реальные пути):

```powershell
npm run media:first-reel:draft -- "C:\\PATH\\TO\\SELECTED_TAKES" "C:\\PATH\\TO\\PRODUCTION-BRIEF.json" "C:\\PATH\\TO\\NEW_DRAFT" "C:\\PATH\\TO\\whisper-cli.exe" "C:\\PATH\\TO\\ggml-multilingual.bin"
```

Команда использует существующий локальный whisper.cpp, FFmpeg и технический QA. Если B04 не совпала с сценарием, она должна остановить автоматический полный монтаж и создать `RECOVERY-RESULT.json` + `editorial-review-kit/previews/review.html`. **Этот статус — ожидаемая защита, а не успешное создание финального MP4.**

## Прослушать конкретную реплику

Открой локальный `review.html`, найди сцену с фразой «Это колыбельная.» (номер сцены и идентификатор B04 могут различаться).

Если диагностика Whisper содержит допустимые timecodes от исходника, рядом с расхождением появятся кнопки:

- **Прослушать фразу** — переход к таймкоду в **реальном локальном видео**, с коротким контекстом до и после.
- **0,8× повтор** — тот же участок медленно, чтобы отличить «Это» от «Эта» и проверить окончание «колыбельная».

Таймкоды распознавателя приблизительные. Полный оригинал доступен в том же блоке. Если кнопок нет, это означает, что нельзя надёжно сопоставить ASR-интервал с доверенным источником — смотри видео целиком. Если фактически прозвучала неверная фраза, пересними B04; не исправляй смысл текста через ослабление ASR-порогов или переписывание субтитров.

Если на реальном аудио слышна **точная** фраза, а ошибся только Whisper, заполни отдельный Recovery Review с достоверными `sourceId`, SHA исходника, началом, длительностью и **услышанным**, а не желаемым текстом. Нажатие «Прослушать» никогда не утверждает выбор и не запускает монтаж.

### Строгая проверка ручной транскрипции

При сохранении ручного выбора страница сравнивает **реально услышанный текст** с утверждённой строкой Production Brief. Серверная команда `media:review:render` повторяет проверку независимо от браузера — подмена или ручное редактирование `selection.reviewed.json` не обходят её.

«Эта колыбельная» **не равна** «Это колыбельная», как и «Это колыбельное»; нельзя менять текст субтитров, чтобы скрыть другую произнесённую фразу. Допустимы только различия регистра, пунктуации, лишних пробелов и орфографическое `ё/е`. Это проверка соответствия текстов, **не доказательство**, что человек действительно произнёс этот текст: первична ручная проверка звука. Если запись не соответствует утверждённой реплике — нужна пересъёмка либо отдельное изменение утверждённого сценария до начала нового монтажного цикла.

## Возобновление после личной проверки

Скачай `selection.reviewed.json` со страницы и выполни:

```powershell
npm run media:review:render -- "C:\\PATH\\TO\\NEW_DRAFT" "C:\\PATH\\TO\\selection.reviewed.json" "C:\\PATH\\TO\\NEW_REVIEWED_RENDER"
```

Этот путь действительно создаёт новый MP4 через FFmpeg **только после явного ручного выбора всех реплик** и перепроверяет SHA источников. Дальше проверь полный MP4 (лицо, очки, цвет кожи, ритм, звук, музыкальную паузу B03, субтитры) и не объявляй его готовым к публикации без отдельной авторской приёмки.

**Что не проверено в GitHub:** реальная фраза пользователя в B04, русская мультиязычная модель на его Windows, художественная и цветовая приёмка конечного MP4. CI проверяет код на тестовых данных и реальный синтетический FFmpeg.
