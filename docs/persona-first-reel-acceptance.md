# Persona — приёмка первого настоящего Reels (P0)

**Цель:** подтвердить один реальный авторский ролик по цепочке: собственные SDR-исходники → локальный Media Worker → черновик 720p → просмотр автора → финал 1080p → Video Quality Lab → платформа → проверенная локальная резервная копия. Здесь нельзя подменять художественную оценку «зелёными» тестами, а автоматическая публикация запрещена.

Состояние на 19 ноября 2026 г.: GitHub main `03c69ed8` с PR #199, #201, #202 прошёл `core`, `web`, `deploy-readiness`; Vercel production READY на обоих проектах. Эти CI-тесты используют технические фикстуры, а не личный исходный материал автора. Данный протокол **не выполнялся на пользовательском ПК**.

## 1. Подготовка — перед первым настоящим монтажом

- Исходники: **2–3 собственных вертикальных SDR-видео**, каждое минимум 8 секунд (общая загрузка не более **500 МиБ**), без HDR/Dolby Vision и поворота в метаданных. Упоминание «вертикальных» — рекомендация для Reels, а не безусловное требование загрузчика.
- Выберите простую сцену, где видно лицо, смену крупности, хотя бы одну актёрскую реакцию и слышно речь. Это позволит проверить **содержание**, а не только кодек. Зафиксируйте, какую мысль должен донести ролик и какую аудиторию он должен заинтересовать.
- Сохраните оригиналы отдельно. Зафиксируйте их исходные контрольные суммы с помощью `Get-FileHash -Algorithm SHA256 <путь>`. Не редактируйте и не переименовывайте исходники во время испытания.
- В корне репозитория выполните `npm run persona:preflight`. Допустимые статусы: `READY_TO_START` либо `ALREADY_RUNNING`; `NEEDS_SETUP` и `BLOCKED` сначала требуют устранения причины.
- Запустите `START_AUTO_RENDER.bat` (обычно `http://127.0.0.1:5173/#persona`) либо `START_PERSONA.bat` (`http://127.0.0.1:3000/#persona`). На iPhone `127.0.0.1` **не подключается** к Windows-компьютеру.
- Выберите «Быстрый черновик», лучше для **первого базового сравнения без Vision**: без ключа OpenRouter нет облачной оценки актёрских моментов. Если ключ есть и Vision включён, отдельные кадры/возможный текст могут отправляться в платный OpenRouter; зафиксируйте этот выбор перед запуском.

## 2. Гейт черновика 720p

Запустите «Сделать всё» и дождитесь статуса проекта «готов». Скачайте черновик и откройте **вне интерфейса Persona**. Запишите его имя, длительность и SHA-256.

**Проверки:** файл открывается полностью, звук синхронен, переходы не уничтожают смысл сцены, не обрезаны лицо и руки, нет случайных чёрных/мёртвых пауз, титры не приписывают человеку непроизнесённые слова. При несоответствии — `NEEDS_FIX`, а не автоматический переход к финалу. Если такой приёмки нет, не нажимайте экспорт 1080p.

## 3. Гейт финального MP4 1080p

Только после просмотра черновика нажмите «После просмотра черновика: 1080p + пакет для соцсетей». Скачайте:
- финальный MP4 **1080 × 1920**, платформенный MP4 для Instagram (если сформирован);
- `video-quality-full.json` (полный QC) и контактный лист кадров JPG (если сформирован);
- исходный и финальный SHA-256, название пресета обработки, статус `fullReady`.

По `video-quality-full.json` проверяйте запись `video.sha256` **ровно для того MP4, который просматривали**, фактические `width`/`height`, `fps`, `audioCodec`, `durationSec`, а также `findings[].id/status/timecodes`.

**Технические блокеры (`NEEDS_FIX`):** MP4 не открывается или не декодируется полностью; SHA-256 не совпадает с QC/receipt; неверные размер или ориентация финального ролика; критическая потеря речи или отсутствие звукового потока, когда речь обязательна; испорченные/ложные титры; нарушенная синхронизация. Исходник изменился — отдельный блокер целостности.

**Предупреждения, требующие просмотра, но не автоматического отказа:** `black_frames` (от 0,2 с), `frozen_frames` (от 0,8 с), `audio_silence` (от 1,5 с), `audio_loudness` (true peak около 0 dBFS), `luma_jumps`, `chroma_jumps`, `scene_visual_consistency`, `subtitles_timing`. Тишина, затемнение или скачок света могут быть осознанным режиссёрским решением. Для каждой такой находки укажите таймкод и решение «исправить / оставить намеренно / невозможно оценить».

Если QC недоступен или поле `not_measured`, **не записывайте «PASS» вместо отсутствующих измерений**. Выполните отдельную ручную проверку и зафиксируйте ограничение.

## 4. Художественная оценка — независимо от FFmpeg

Оцените 6 категорий по шкале `0 = невозможно оценить`, `1 = серьёзный недостаток`, `2 = нужна доработка`, `3 = можно показывать индустрии`, `4 = сильное решение`:

| Категория | Что именно проверять |
| --- | --- |
| Актёр и эмоция | Живые реакции, паузы, интонация, сохранность игры; не подменены ли удачные дубли невыразительными |
| Драматургия и хук | Событие/конфликт с первых секунд, ясность мысли без длинного объяснения, темп, сильная концовка |
| Кадр и цвет | Лицо и кожа выглядят естественно; нет желто-зелёного оттенка, излишней резкости, клиппинга светов, случайной обрезки рук/клавиш |
| Монтаж и ритм | Склейки поддерживают смысл, не прячут эмоцию, нет беспричинных переходов; музыкальные акценты попадают в действие |
| Речь, музыка и звук | Слышимость и разборчивость речи, естественный тембр, отсутствие перегруза, баланс фоновой музыки |
| Титры и платформенная версия | Точный текст, таймкоды, читаемость на экране телефона, безопасная зона Instagram, обложка и упаковка |

**Гейт «можно показывать индустрии»:** ни одной технической блокирующей ошибки; каждое применимое художественное направление оценено **не ниже 3** после осознанного авторского просмотра. Это договорной критерий первого эксперимента, а не машинная метрика таланта. Исключения документируются; автоматического утверждения/публикации нет.

## 5. Сохранность проекта и итог

По [инструкции архивирования одного задания](persona-worker-job-backup.md) остановите Media Worker, создайте **новый архив вне основного диска**, выполните `verify` и сохраните отчёт SHA-256. Ни исходный файл автора, ни папку существующего проекта при восстановлении перезаписывать нельзя. Браузерные редакционные материалы сохраняются **отдельно**.

Итог по каждому этапу отмечайте `PASS`, `NEEDS_FIX`, `BLOCKED` либо `UNVERIFIED`. Только после завершения всех применимых этапов и решения автора можно обсуждать публикацию. Не переводить `REVIEW_REQUIRED` в автоматический `PASS`.

### Короткий протокол результата

```text
Persona first reel / дата:
Worker / preflight:
Имя и хэши исходников (до/после):
План ролика / цель / аудитория:
Vision: OFF / ON / FAILED; облачные запросы:
720p draft: файл, SHA-256, авторская оценка:
1080p master: файл, SHA-256, размер, FPS, звук:
QC JSON: SHA-256 MP4 совпал? warnings с таймкодами:
Контактный лист: есть / нет:
Художественный балл (актёр/хук/цвет/монтаж/звук/титры):
Критические замечания и что исправлено:
Архив Worker: место, verify=PASS / NOT_DONE:
Браузерный ZIP: сделан / не сделан:
Общий статус: PASS / NEEDS_FIX / BLOCKED / UNVERIFIED:
Решение автора о публикации: отдельно, по умолчанию НЕТ
```

Для независимого анализа можно приложить черновик, финальный MP4, QC JSON и контактный лист. Без самих кадров и аудио реальное актёрское, цветовое и музыкальное качество **не подтверждается**.
