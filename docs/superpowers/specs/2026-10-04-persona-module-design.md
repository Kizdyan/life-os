# Persona Module Design

## Цель
Встроить Persona в Life OS как отдельный модуль, используя существующий Media Brain как техническое ядро. Persona должна довести контент от сигнала/идеи до готового пакета, запросить у пользователя только решение «Опубликовать / Переделать / Отложить / Отклонить», затем автоматически публиковать через доступные официальные интеграции, собирать статистику и возвращать её в цикл обучения.

## Границы
- Persona живёт в репозитории Life OS, но остаётся модульной.
- Существующие стабильные функции Life OS не переписываются ради Persona.
- Media Brain, MediaStateStore, автономный runtime, Yandex.Disk state/lease и существующие media API переиспользуются.
- Instagram, VK и YouTube подключаются адаптерами; отсутствие возможности официального API не маскируется.
- Публикация, требующая утверждения, невозможна без явного решения пользователя.

## Пользовательский поток
Сигнал → кандидат идеи → оценка → съёмочное задание → исходник → обработка → версии площадок → контроль качества → Центр утверждения → расписание → публикация → проверка → метрики → Content DNA → следующие идеи.

## Интерфейс
В Life OS появляется отдельный раздел Persona. Главный экран — очередь решений, а не сложная панель управления. Карточка содержит предпросмотр, краткую причину рекомендации, выбранные площадки и четыре действия: Опубликовать, Переделать, Отложить, Отклонить. Технические настройки скрыты вторым уровнем.

## Данные
Состояние Persona расширяет существующее версионированное media state аддитивными полями: approval, platform variants, publication jobs, metric snapshots, learning signals. Старые snapshots остаются читаемыми через значения по умолчанию.

## Публикация
Каждая площадка получает независимое задание с idempotency key. Состояния: approved → scheduled → publishing → published → verified; ошибки: retry_wait / blocked / failed. Перед повторной отправкой проверяется, не произошла ли публикация уже.

## Аналитика и обучение
Метрики сохраняются временными снимками. Сравнение ведётся внутри одной площадки и с сопоставимыми материалами. Один ролик не должен радикально менять стратегию. Повторяемые сигналы обновляют веса Content DNA и влияют на генерацию/отбор следующих идей.

## Надёжность
Временные ошибки повторяются ограниченно с увеличением интервала. Блокирующие ошибки эскалируются пользователю. Автономные workers используют существующую распределённую блокировку, чтобы исключить двойную обработку/публикацию.

## Интеграция с Life OS
Persona может получать разрешённые события, проекты и milestones Life OS как content signals и возвращать shoot tasks, approval-required и итоговые аналитические сигналы. Ядро Persona не должно зависеть от конкретного UI планировщика.

## Критерий готовности
30-дневный цикл можно провести без ручного ведения Instagram/VK/YouTube для рутинных операций, кроме действий, которые конкретная площадка технически требует от пользователя. Вся история решений, публикаций и обучения сохраняется и переживает перезапуск runtime.
