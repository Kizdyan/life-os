# Persona: авторский сценарий и локальные файлы

Откройте работающую локальную Persona: http://127.0.0.1:5173/#persona.

1. Создайте Reels. На «Идея» нажмите **Вставить свой сценарий**.
2. Вставьте готовый текст. Каждый кадр должен содержать плановый интервал, например `0–2 сек: Читаешь сообщение. (Текст: БЮДЖЕТ НА ОДНОГО)`.
3. Произносимые слова пометьте `Реплика:` или `Голос:`. Экранный `Текст:` не считается речью. Дополнительные строки указаний сохраняются. Нужны 2–30 кадров; для покадровой загрузки текущий Worker принимает 2–12 файлов, до 2 ГБ каждый / 4 ГБ суммарно.
4. Нажмите **Разобрать сценарий без творческой критики**. Настоящая локальная Qwen возвращает ограниченный JSON; код сверяет каждую реплику и цитату с авторским текстом. Ошибка или недоступность модели не заменяется шаблоном.
5. Проверьте полный пакет и нажмите **Подтвердить мой сценарий и перейти к съёмке**. Это ваше утверждение сценария, не утверждение готового видео и не публикация. Новая редакция хранится в истории; исходный вставленный текст и SHA-256 остаются в брифе.
6. На «Съёмка» снимайте по шпаргалке. Выберите подготовленные короткие MOV/MP4 в панели локального Worker. Имена `001.mp4` … `011.mp4` автоматически предлагают номера кадров; проверьте и при необходимости исправьте назначение. Для ручного покадрового режима нужен ровно один выбранный файл на каждый кадр. Альтернативные дубли автор выбирает явно.
7. Длительность проверяется в браузере и независимо через FFprobe после локального копирования. Для короткого дубля лимит `min(60, max(15, план × 3))` секунд. Длинный разговорный мастер (до 15 минут) поддерживается отдельным режимом только для сценария со сплошными явными репликами; визуальный план требует отдельных файлов.
8. Нажмите **Смонтировать ИИ**. Whisper проверяет произносимые реплики. Визуальные кадры используются целиком по вашему назначению, без фиктивных транскриптов и без автоматического усиления их музыки. Неуверенная речь отправляется в Recovery Review.
9. После успешного QA просмотрите MP4 и нажмите **Сделать 4 версии для соцсетей** (также доступно на «Выпуск»). Ссылки и точные локальные пути сохраняются в проекте. Reload восстанавливает результат при том же работающем Worker.

## Что сохраняется

В браузере: текст сценария, версии брифа, подтверждение, ссылки на результаты. MP4 не хранится в localStorage. Worker получает только выбранные байты через localhost и создаёт новые папки в настроенном `output-root`. Оригиналы не перемещаются и не перезаписываются. При неудачном импорте удаляется только принадлежащая Worker незапущенная staging-папка; результаты анализа сохраняются для диагностики.

## Четыре версии и ограничения

- TikTok/Shorts: Dynamic, крупные контрастные вшитые титры, предел 30 с.
- Instagram: Commercial Cinematic, титры «шампань», мягкие видеостыки 120 мс без изменения аудиограниц.
- VK: Cinematic, полный доступный контекст; при нехватке материала до 40 с показывается предупреждение.
- YouTube: полная подтверждённая последовательность, предел 600 с.

Авторские реплики и порядок кадров не переписываются. Если материала не хватает для разных редакций, система не выдумывает контекст, не повторяет кадры и не растягивает музыку. Четыре файла могут иметь одинаковый монтаж и отличаться оформлением. Превышение лимита платформы требует авторского сокращения. Система не сочиняет оркестровку и не доказывает попадание в tutti; используется записанный звук. Положение титров относительно лица проверяет автор. Без заданных титров визуальный монтаж остаётся без выдуманных субтитров.

HDR/BT.2020, поворот в метаданных и повреждённые файлы блокируются с причиной. Скрытой HDR→SDR или изменения ориентации нет. Если браузер не читает кодек, потребуется отдельная совместимая SDR-копия; оригинал сохраняется.

Файл архетипа `tools/my-archetype.json` сохранён и проверяется прежними тестами. Он не используется для переписывания ручного сценария. История Generator-Critic доступна для чтения; творческая генерация Qwen в этом UI отключена.

Публикация всегда запрещена: publicationApproved=false, distributionAllowed=false. Синтетический E2E проверяет механизм, не художественное качество настоящей съёмки.


## Приёмка реальных файлов: тип каждого кадра и ASS

После выбора файлов у каждого назначения есть **Речь / Визуал**. Для речи проверьте поле ожидаемой реплики: оно берётся из сценария, а не из имени файла. Если реплика находится внутри экранного титра, например `Композитор: «Мне нужна минута»`, выберите «Речь» и подтвердите точную цитату. Новые слова через это поле вводить нельзя. Если в сценарии уже явно указана «Реплика:», метка «Визуал» не отменяет её: нужна отдельная правка сценария. Типы относятся к конкретному запуску и SHA каждого выбранного файла; исходный текст брифа не переписывается. После reload типы видны в сохранённом результате.

Whisper получает только речевые файлы. Визуальные файлы используются по назначению кадра целиком, без требований произнести экранный титр. В принадлежащей Worker staging-папке `take-bindings.json`, а в папке результата `RESULT.json` сохраняют типы и SHA; монтажные решения содержат те же привязки.

Субтитры уже рендерятся через FFmpeg/libass и сохраняются в `.ass` рядом с MP4. Семейства шрифтов читаются из `tools/visual-presets.json`, жёсткого Arial по умолчанию нет:
- Cinematic: Segoe UI Light, белый, мягкая тень и спокойное появление.
- Dynamic: Segoe UI Bold, контрастная обводка, акцент на длинном слове фразы (это типографическая эвристика, не семантическое распознавание ключевых слов).
- Commercial: Segoe UI, строгий гротеск и «шампань».

Это установленные шрифты Windows; скачивание не требуется. На другой ОС libass может подобрать замену. Фактически выбранный шрифт фиксируется в `*.persona-subtitles.json` (`fontSelections`); оформление требует просмотра на реальном кадре.

## Необязательные идеи OpenAI / Perplexity

На «Идея» есть **Сгенерировать идеи (Perplexity/OpenAI)**. Без ключа она показывает настройку, а ручной ввод продолжает работать.

Скопируйте `.env.example` в `.env.local` этого checkout и впишите нужный ключ. Worker читает этот игнорируемый Git файл при запуске; перезапустите его после изменения. Не используйте `VITE_` для ключей и не вставляйте секреты в браузер или `my-archetype.json`.

Ключ Perplexity создаётся на [API Keys в официальной консоли](https://console.perplexity.ai/project/keys). Если проекта ещё нет, сначала создайте его в консоли. Вставьте ключ после `PERPLEXITY_API_KEY=` в локальном `.env.local`; без ключа ручной сценарий и монтаж доступны, живой вызов Perplexity не проверен.

```dotenv
OPENAI_API_KEY=
PERPLEXITY_API_KEY=
PERSONA_IDEAS_OPENAI_MODEL=gpt-4.1-mini
PERSONA_IDEAS_PERPLEXITY_MODEL=openai/gpt-5.6-sol
```

Только явный подтверждённый клик отправляет тему, архетип и авторские примеры выбранному провайдеру. Платные вызовы не выполняются на старте/при переходе между шагами. Видео, кадры, пути к вашим файлам и транскрипты монтажного задания не передаются. За один клик — один ограниченный запрос без автоматических повторов; локально не больше пяти попыток в час. Полученные идеи остаются предложениями: выберите текст, просмотрите пакет и подтвердите сценарий отдельно.

Интеграция использует [официальный OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create) и [Perplexity Agent API](https://docs.perplexity.ai/docs/agent-api/quickstart). Она не объявляется исследованием трендов. Без ключей живой вызов API не считается проверенным; контрактные тесты не заменяют его.

Архетип в `tools/my-archetype.json` — Independent Artist: Quiet Luxury / Old Money without snobbery, Freedom through creativity, точность и ирония без пафоса. Все пять полей, включая три направления контента, попадают в текстовый запрос. Сохранённые старые редакции архетипа остаются читаемыми; обновление конфига не переписывает авторский сценарий.

**Важно для «Бюджета на одного»:** эталон `docs/persona-commercial-examples.md` содержит ровно **11 монтажных кадров (0–24 с)** по утверждённой шпаргалке. Файл №11 — план с кофе; тройная склейка профессий в его начале использует уже снятые кадры №2–4. Это один финальный монтажный интервал, а не двенадцатый исходный файл. Локально утверждённые редакции в браузере сохраняют историю и не переписываются автоматически при обновлении Git.
