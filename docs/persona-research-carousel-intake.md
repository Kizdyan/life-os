# Persona: исследовательская карусель — первый рабочий этап

**Реализовано в PR #213** как первый этап [issue #212](https://github.com/Kizdyan/life-os/issues/212). Это работа внутри существующей **Persona Factory → Editorial Desk**, не отдельный генератор.

## Как пользоваться

1. Открой Persona → «Редакция: карусели и фото» → «Все темы».
2. Раскрой **«Создать карусель из исследования»**.
3. Кнопкой **«Скопировать исследовательский промпт»** возьми точную схему для Perplexity; отправь её в Perplexity вручную. При отсутствии источников можно подготовить JSON самому.
4. Вставь **JSON**, состоящий из `title`, `angle`, `caption` и массива `slides` (от 5 до 7). Слайд содержит `text` (до 260 знаков), необязательное `visualDirection` и одно из:
   - `sources`: 1–4 объекта с `title` и реальным `url`;
   - `interpretation: true`: только для **авторского мнения без фактических утверждений**.
5. Нажми «Импортировать как черновик». Persona создаст **новый**, а не перезапишет предыдущий редакционный проект. Всё импортированное остаётся `UNVERIFIED`.
6. Утверди тему, затем на шаге текста открой каждый источник и отметь «Проверено по оригиналу» **только при реальном совпадении факта с источником**. Непроверенные факты блокируют `SOURCE_PASS` и утверждение текста.
7. После утверждения текста выбери графитово-шоколадный пресет. Для каждого слайда доступен **точный Canvas PNG** в формате 1080×1350 и отдельное скачивание на телефон для оценки. Если есть собственная фотография, можно выбрать её из имеющегося архива. Случайные чужие лица не генерируются.
8. Пройди визуальный чек-лист и утверди оформление. В ZIP будут PNG, чистый `caption.txt` и отдельно `research-sources.json`. ZIP не публикует пост в соцсети.

## Границы доказательности

- `SOURCE_PASS` означает **ручное подтверждение автором**, а не сетевую проверку содержимого URL. Наличие ссылки не считается доказательством.
- Изменение фактического текста снимает подтверждение относящихся к нему источников. Изменение подписи или темы снимает их все.
- Неопределённые источники и художественное качество не получают автоматический зелёный статус.
- При недоступном провайдере **не выдумываем факты, ссылки и результаты генерации**.
- Исследование с нуля через Perplexity и создание кинематографических фоновых изображений *не реализованы этим PR*. В исходном `api/persona-research.ts` Perplexity только детектируется как `configured_but_inactive`; Worker `/external-ideas` предназначен для идей, а не доказанной проверки фактов.
- Этот импорт не изменяет исторические карусели №1–4, оригиналы пользовательских фотографий или уже утверждённые проекты.

## Пример минимального JSON

```json
{
  "title": "Музыка как драматическое действие",
  "angle": "Проверяемая история из кинопроизводства",
  "caption": "Подпись с новой мыслью, не повторяющая слайды.",
  "slides": [
    {"text":"Неожиданный факт с первого экрана","visualDirection":"Крупный план музыкального инструмента, без лиц","sources":[{"title":"Первоисточник","url":"https://example.org/original"}]},
    {"text":"Следующее обстоятельство","sources":[{"title":"Статья","url":"https://example.org/second"}]},
    {"text":"Новая деталь","sources":[{"title":"Интервью","url":"https://example.org/third"}]},
    {"text":"Непредвиденный поворот","sources":[{"title":"Интервью","url":"https://example.org/third"}]},
    {"text":"Содержательный авторский вывод","interpretation":true}
  ]
}
```

*Ссылки `example.org` в образце являются заглушками для проверки структуры, **не источниками фактов**. Для реального материала их необходимо заменить.*

## Инженерные проверки

Тесты: `apps/web/src/personaResearchCarousel.test.ts`. Проверяются некорректные ссылки, запрет пропуска источников, состояние `UNVERIFIED`, ручное подтверждение, инвалидация после редактирования и отсутствие регрессии сохранённого Editorial Store.

Перед merge должны пройти `npm test`, `npm run typecheck`, `npm run api:typecheck`, `npm run web:build`, сборка публикационных каруселей и визуальная проверка в браузере/на телефоне. Автогенерация **не объявляется готовой** без реального сквозного теста с провайдерами.
