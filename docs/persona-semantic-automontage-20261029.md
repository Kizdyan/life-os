# Persona · Смысловой автомонтаж: рабочий прототип, 29.10.2026

## Что реализовано

Ветвь дополняет существующий FFmpeg-редактор Persona, ничего не заменяя. Локальный скрипт tools/persona-semantic-montage.mjs поддерживает две команды: analyze и assemble.

**analyze** читает только явно перечисленные видео, проверяет их FFprobe, фиксирует исходные SHA-256, выделяет три JPEG-кадра, моно WAV для распознавания речи и интервалы тишины. Никаких сетевых запросов, AI-вызовов, перезаписи исходников. Вход: JSON с version=1 и sources=[{id,path},...]. Команда: node tools/persona-semantic-montage.mjs analyze sources.json ./new-evidence-dir. Результат: new-evidence-dir/analysis.json и локальные медиа-свидетельства.

**assemble** читает decision JSON с version=1, analysisPath, briefPath, choices. Для каждого сценарного кадра решение содержит beat (порядковый номер), sourceId, startSec, durationSec, transcript, confidence (0..1), reason. Обязательно одно решение на каждую реплику, с правильным порядком, проверенными временными границами, уверенностью не ниже 0.65 и минимальным совпадением реплики с расшифровкой. Проверяется SHA-256 неизменённых исходников. Команда: node tools/persona-semantic-montage.mjs assemble decisions.json ./fresh-timeline.json. Результат — настоящий входной проект для существующего tools/persona-timeline-render.mjs и отдельный *.review.json со статусом needs-human-review.

После этого можно использовать уже существующие команды:

- node tools/persona-timeline-render.mjs fresh-timeline.json fresh-reel.mp4
- node tools/persona-verify-render.mjs fresh-reel.mp4 first-reel reel fresh-qa.json

**Portable FFmpeg для Windows:** процессные переменные PERSONA_FFMPEG и PERSONA_FFPROBE могут указывать на абсолютные пути к исполняемым файлам. Не требуется менять системный PATH. Существующий рендерер по-прежнему требует доступных в его процессе команд ffmpeg и ffprobe (допустим временный PATH только текущего процесса).

## Что ещё НЕ работает автоматически

Этот модуль НЕ является самостоятельной мультимодальной моделью. Он пока не делает распознавание речи, смысловое понимание видеокадров, распознавание удачной актёрской игры или генерацию choices. Для настоящего ИИ-режиссёра нужна отдельная, разрешённая пользователем стадия ASR + визуального анализа фрагментов + поиска лучшего дубля относительно сценария. Нельзя отправлять лицо/голос пользователя во внешнюю модель без разрешения. Платные вызовы по умолчанию отключены.

Три статичных кадра по видео полезны для первичного просмотра, но недостаточны для точного понимания эмоций и движения. Реальные video/audio quality gates и творческая проверка перед публикацией обязательны.

## Практическая цель

1. Взять собственные утверждённые видео пользователя (не чужой референс).
2. Получить фактические медиа-данные локально; транскрибировать речь только разрешённым способом.
3. Составить решения о выборе дублей и границ обрезки настоящей моделью или редактором, с объяснением и уверенностью.
4. Пропустить их через assemble, уже существующий FFmpeg рендер и QA.
5. Проверить цвет, очки, лицо, интонацию, музыку, субтитры, обложку человеком.
6. После согласования подготовить публикацию в Instagram.

## Технические ограничения и безопасность

Максимум 12 файлов до 180 сек на файл, максимум 2 ГБ на источник. В assemble нужны от двух до тридцати плановых кадров; исходники проверяются хэшами, а выходы создаются только в новых местах, без перезаписи. JSON от AI не может подставить редакторское утверждение. Семантическое совпадение текста — предварительный фильтр, не доказательство верного смысла. Никакого автоматического опубликования.

**Честный статус:** локальная подготовка и сборка семантически обоснованного монтажного листа реализованы. Полноценный AI-автомонтаж на личных исходниках ещё не прошёл испытания.
