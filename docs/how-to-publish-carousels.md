# Как опубликовать карусель из GitHub Releases

Для скачивания не нужно открывать Persona, запускать компьютерные команды или пользоваться редактором.

1. Откройте [список GitHub Releases проекта](https://github.com/Kizdyan/life-os/releases). Выберите выпуск «Persona: 4 карусели». **Пока этого выпуска нет, ссылка ведёт только на список — готовых ZIP не существует.**
2. В блоке **Assets** скачайте ZIP с названием нужной карусели или общий ZIP с именем persona-carousels-publish-YYYY-MM-DD.zip.
3. Распакуйте скачанный ZIP. На iPhone используйте приложение **«Файлы»**: откройте «Загрузки», коснитесь ZIP, затем откройте папку нужной карусели.
4. Откройте Instagram → **+** → **Публикация**. Выберите шесть фотографий slide-01.png … slide-06.png **строго по порядку**.
5. Скопируйте текст из caption.txt в подпись публикации. Прочтите, проверьте оформление и **опубликуйте вручную**.

В каждой папке также есть publish-instructions.txt с короткими шагами и checklist.json с данными редакционного утверждения. Ни GitHub, ни Persona не публикуют посты в Instagram автоматически.

Для каруселей №3 и №4, если не были выбраны архивные фотографии, публикуется **текстовая версия**. Чтобы перейти к авторским фото, нужно выбрать оригиналы в существующем архиве Persona и заново утвердить оформление.

**Защита от ошибочной публикации:** релизный сборщик не создаёт настоящие ZIP при отсутствии четырёх действительных подтверждений темы, текста, оформления и чек-листа; тестовые утверждения GitHub Actions не считаются утверждением автора. Если релиз не появился, это не ошибка телефона: готовые материалы пока не выпускались.
