# Agent instructions for Life OS / Persona

Before changing code, read [PROJECT_GOALS.md](PROJECT_GOALS.md), [DEPENDENCIES.md](DEPENDENCIES.md), [ACCEPTANCE_CRITERIA.md](ACCEPTANCE_CRITERIA.md), and [AI_WORK_PROTOCOL.md](AI_WORK_PROTOCOL.md).

## Execution contract
- Work on the authorized feature branch, never on `main` without explicit approval.
- One smallest testable task at a time; identify the outcome and required evidence before editing.
- Inspect existing code, apply a minimal change, read back the resulting file/diff, then run tests on the exact commit.
- Report **implemented**, **verified**, and **blocked** separately. No test execution means no PASS claim.
- Never spend money, create a paid service, alter production, delete data, merge or override creative approval without permission.
- No user's desktop is required for routine validation or production. If cloud CI is blocked, document the actual blocker and find an isolated authorized executor.
- For Reels and carousels: research -> multiple ideas -> independent editorial review -> user-approved script -> shoot plan or slide plan -> production -> quality review -> analytics.
- Protect original media, existing project names and live deployments.
